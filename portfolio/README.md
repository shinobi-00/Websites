# Vishal Raj — portfolio

Static site, no framework. Opens straight from `index.html` or any static host.

| File | What it does |
|---|---|
| `profile.js` | **All content** (text, metrics, roles, languages). Edit this to update the site. |
| `app.js` | Renders `profile.js` into the page, one function per section. |
| `index.html` | Page shell: header, empty sections, footer. |
| `tailwind.config.js` | Design tokens (colours, fonts). |
| `src/input.css` | Tailwind entry + a few base rules. |
| `assets/styles.css` | Compiled CSS (generated, don't edit). |
| `assets/vendor/lucide.min.js` | Lucide icons (generated by `npm run build`). |
| `assets/Vishal_Raj_Resume.pdf` | Resume served by the download buttons. |

## Change something
1. Edit `profile.js` (content) or classes in `app.js` (layout).
2. If you added new Tailwind classes: `npm install` once, then `npm run build` (or `npm run watch` while editing).
3. Preview: `npm run serve` → http://localhost:8000

## Publish free on GitHub Pages
Create a repo named `<your-username>.github.io`, push these files, and enable Pages (Settings → Pages → Deploy from branch → main). The site appears at `https://<your-username>.github.io`.
